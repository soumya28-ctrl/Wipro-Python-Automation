
# 🛒 E-Commerce Website Automation Testing using Selenium

## 📌 Project Overview

This project is an **E-Commerce Website Automation Testing** project developed using **Python and Selenium WebDriver**.

The main objective of this project is to automate and validate important user actions on an e-commerce website, including:

- Opening the e-commerce website
- User login
- Searching for a product
- Adding a product to the shopping cart
- Increasing the product quantity
- Validating the cart functionality
- Capturing screenshots during test execution

This project demonstrates the practical use of **Selenium WebDriver for web application automation testing**.

---

## 🎯 Project Objectives

The key objectives of this project are:

- Automate real-world e-commerce user workflows.
- Verify that the login functionality works correctly.
- Automate product search functionality.
- Verify that products can be added to the shopping cart.
- Test whether the product quantity can be increased successfully.
- Capture screenshots at different stages of test execution.
- Gain practical experience with Selenium WebDriver and automated testing.
